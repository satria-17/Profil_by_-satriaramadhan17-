## Struktur repository

```
profilProfil_by_satriavictor/
├── index.html
└── README.md
```

## Cara menjalankan di komputer

1. Unduh atau clone repository ini.
2. Buka file `index.html` dengan browser (klik dua kali).

Untuk clone lewat terminal:

```bash
git clone https://github.com/<username>/profilProfil_by_satriavictor.git
cd profilProfil_by_satriavictor
```

## Cara menampilkan online dengan GitHub Pages

1. Buka **Settings**, lalu **Pages** di repository ini.
2. Pada **Source**, pilih **Deploy from a branch**.
3. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
4. Tunggu beberapa menit. Halaman akan tersedia di:
   `https://<username>.github.io/profilProfil_by_satriavictor/`

## Cara mengubah isi

Buka `index.html` dengan editor teks (misalnya VS Code), lalu ganti:

- Nama perusahaan di logo, judul, dan footer
- Teks pada bagian Tentang kami dan Layanan
- Nama dan jabatan pada bagian Tim kami
- Alamat, email, telepon, dan jam kerja pada bagian Kontak

Warna dan gaya tampilan ada di dalam tag `<style>` di bagian atas file.
